# Promote the model into an empty model directory

Slug: build-model-promotion-empty-directory-recovery
Model: not applicable — the change is a single-step filesystem promotion with no state machine to model
Acceptance:

Fix kogen-build model promotion after native recovery leaves an empty model directory. Owner delivery/kogen-build; the accountable consumer is delivery/studio, and the implementation and regression tests stay in kogen-build. The affected Studio original is row 41338999-c354-4803-8ee9-9a0d1369a403, attempt a07739e6e77449eeb23ea945dc7969a9, second native Build a8273748, which remains at builder_verify with candidate tree 905dd173549e7d71e6873dcdb5703f558b367d47; the first Build d2dd6149 produced model files that its recovery archived and cleared. Builds 31f15ae197ef (f923544e) and 6f463750c981 (fb791b24) skip promoteModel when `.kogen/models/<slug>` exists, and maintained-model enumeration then fails opening model.json.

At the verification boundary, when exact approved Intent evidence makes the current candidate the owner of a missing or empty `.kogen/models/<slug>` directory, the Build materializes the pair (`model.qnt`, `model.json`) from the exact currently approved model source and manifest parameters, then proceeds through maintained-model enumeration and verification. The pair is published as one complete update, or the pre-existing state stays intact on interruption; the acceptance observes only that no half model is ever visible. Ambiguous ownership, partial or conflicting files, an invalid or missing model source or a changed approval are an actionable refusal. Existing complete maintained models, including unrelated slugs, are preserved byte for byte, and ordinary model-less Builds work as before. The change replaces the old rule "skip when the directory exists" with "skip only when the directory holds a complete pair".

Out of scope: generic changed-candidate continuation (its own existing issue), the Studio row, the operational handoff (Factory custody, waits, admission and retry; the earlier recovery archive stays comparison evidence; the original candidate stays parked until a qualified public release and a supported continuation receipt prove it can consume a8273748; if native continuation cannot validate a8273748, the original evidence is preserved and an explicit supported disposition is awaited). This submission is the component fix only.

## Decisions
- Promotion happens in `promoteModel` at the verification boundary for an Intent whose approved model is present; a missing or empty `.kogen/models/<slug>` is filled from the approved source bytes and manifest parameters of that Intent, never from archived bytes. (evidence: build/maintained.go; build/build.go) (source: request)
- Filling requires the saved approval to be unchanged and the model source to equal its approved baseline digest and be non-empty; otherwise the Build stops with a refusal that names the directory and writes nothing. (evidence: build/review_retry.go; build/build.go) (source: request)
- Publish the pair atomically: stage model.qnt and model.json in a private directory under .kogen/local and replace the target directory with one rename, so an interruption leaves the earlier empty or missing state. (decision: D2, round 1) (evidence: build/maintained.go) (assumption: Rename of a directory over an empty one was observed on Linux only.) (source: request)
- A non-empty `.kogen/models/<slug>` is accepted and left untouched only when it holds exactly `model.qnt` and a `model.json` that decodes and names that directory's `model.qnt`; any other contents, or a non-directory, are refused with an error naming the directory and nothing is written. (evidence: build/maintained.go; build/maintained_test.go) (assumption: a complete pair that differs from the approved source is preserved as the existing maintained model, not compared or replaced) (source: request)
- Approval drift, a changed or missing approved model source and a mismatched Build identity or checkpoint refuse before any model is written and leave repository and checkpoint unchanged; resume's existing guards already refuse them and the acceptance keeps that true with the empty directory present. (evidence: build/resume.go; build/review_retry.go) (assumption: the fixture reaches the resume path from an interrupted Build, which is equivalent to but not byte-identical with the Studio checkpoint a8273748 at builder_verify) (source: request)
- Unrelated slugs' complete models and Builds whose Intent has no model are unchanged: no promotion, no deletion, no regeneration; maintained enumeration still verifies every complete model. (evidence: build/maintained.go; build/maintained_test.go) (source: request)
- At the verification boundary, promoteModel fills a missing or empty .kogen/models/<slug> directory of an approved model Intent from the exact approved model source and manifest parameters; the source must equal its approved baseline digest and the saved approval must be unchanged, otherwise promotion is refused. (decision: D1, round 1) (evidence: build/maintained.go; build/build.go; build/review_retry.go) (assumption: The fixtures only observed behavior on Linux in scratch runs by an external session; the retained Studio Build a8273748 itself was not available.) (source: request)
- A non-empty directory is kept only when it holds exactly model.qnt and a model.json that decodes and describes that directory's model.qnt; every other content, or a non-directory, is an actionable refusal naming the directory, with nothing written. (decision: D3, round 1) (evidence: build/maintained.go; build/maintained_test.go) (assumption: A complete pair that differs from the approved source is preserved, not compared: this is the existing behavior the request asks to keep.) (source: request)
- Approval drift, a changed or missing approved model source and a mismatched Build identity are already refused by resume before verification; the acceptance proves this still holds with an empty directory present, and the promotion adds its own guard (baseline, saved approval, source digest) for the same facts. (decision: D4, round 1) (evidence: build/review_retry.go; build/resume.go) (assumption: The independent Review and the commit binding are not exercised by the fixture, which uses the approve-without-review test reviewer; they are existing behavior unchanged by this fix.) (source: request)
- Model-less Builds and unrelated slugs' complete models are untouched and still enumerated and verified. (decision: D5, round 1) (evidence: build/maintained_test.go) (assumption: none) (source: request)
